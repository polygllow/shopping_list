# Shopping List

Консольное приложение на Python для управления списком покупок.

## Описание

Программа позволяет добавлять и удалять товары, просматривать текущий список и очищать его. Список хранится в памяти в виде строки, товары разделены запятой и пробелом (`, `).

## Требования

- Python 3.6 или выше

## Запуск

```bash
python shopping_list.py
```

## Команды

| Команда | Описание | Пример |
|---|---|---|
| `add <товар>` | Добавить товар в список | `add молоко` |
| `remove <товар>` | Удалить товар из списка | `remove молоко` |
| `list` | Показать текущий список | `list` |
| `clear` | Очистить список | `clear` |
| `exit` | Выйти из программы | `exit` |

## Пример работы

```
Введите команду: add молоко
Товар молоко добавлен.
Введите команду: add хлеб
Товар хлеб добавлен.
Введите команду: list
молоко, хлеб
Введите команду: remove молоко
Товар молоко удален.
Введите команду: list
хлеб
Введите команду: clear
Список очищен.
Введите команду: exit
```

## Особенности

- Повторное добавление товара, который уже есть в списке, игнорируется с сообщением.
- Удаление отсутствующего товара сообщает об ошибке.
- При добавлении пустого названия выводится подсказка.
- Регистр имеет значение: `Молоко` и `молоко` считаются разными товарами.
